SPIKE DETECTION LOGIC
function detectStressSpike(bpm, baseline) {
  const SPIKE_MIN = 110;
  const DEVIATION = 20;
  return bpm > SPIKE_MIN
    && bpm - baseline >= DEVIATION;
}

How this module fulfils the crowdsourcing protocol

⏱️
30-SECOND READINGS
Heart rate recorded every 30 seconds alongside GPS coordinates at that precise moment during an active trip.
📍
GPS COORDINATE LOGGING
Each reading is tagged with timestamp and location. Stress spikes include full metadata: BPM, baseline, deviation, and coordinates.
🧮
BASELINE CALIBRATION
Average BPM from the first 5 minutes of the journey establishes the personal baseline — used by the spike detection function.
🌐
ANONYMOUS CROWDSOURCING
Detected spike locations are anonymously contributed to the community safety map as physiological danger signals — unsafe zones from pure body data.
