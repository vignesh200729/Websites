Section 05

HTTP vs HTTPS

The single letter "S" stands for a fundamentally different level of trust.

HTTP

YOU ───────────→ SERVER
"password123"

Data travels in plain text. On an unsecured network, this traffic could potentially be observed or altered in transit.

HTTPS

YOU ── 🔒 ENCRYPTED ──→ SERVER

Data is scrambled using TLS encryption before it leaves your device, so only the intended server can read it, verified by a digital certificate.

Section 06

Every Connected Device Needs an Address

Just like a postal address for a house, an IP address tells the network exactly where to deliver data.

IPv4
192.168.1.10

The older, shorter format. About 4.3 billion possible addresses — not enough for today's connected world.

IPv6
2001:db8:85a3::8a2e:370:7334

The newer, longer format. Provides a virtually unlimited pool of addresses for modern devices.

Private IP

Used only inside your home or office network — your router assigns one to your laptop, phone, and smart devices.

Public IP

The address your ISP assigns your network on the open Internet — how the rest of the world reaches you.
